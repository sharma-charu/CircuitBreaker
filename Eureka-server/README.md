# Eureka Server

## Overview

This project implements the Eureka Service Registry for the CircuitBreaker
cloud-native e-commerce application.

## Deployment

The Eureka Server is deployed on Render.

### Eureka Dashboard
https://circuit-breaker-s6d7.onrender.com

### Health Check
https://circuit-breaker-s6d7.onrender.com/actuator/health

## Services

The Eureka Server is used for service discovery between microservices
such as Inventory Service and API Gateway.
